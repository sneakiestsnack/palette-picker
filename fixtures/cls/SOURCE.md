# .cls reference files

`AABBCC.cls` and `unicode.cls` are test files from **CLSEncoderDecoder** by Equbuxu
(https://github.com/Equbuxu/CLSEncoderDecoder, `CLSEncoderDecoderTest/files/`), MIT License.
They are used only as byte-exact references for this project's `.cls` writer tests.

- `AABBCC.cls`: color set named `AABBCC` with one color, RGBA `AA BB CC FF`.
- `unicode.cls`: color set named `a\u00A1\u0800\u{12000}` ("a¡ࠀ𒀀") with one color, RGBA `AA BB CC FF`.
